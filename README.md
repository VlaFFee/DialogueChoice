# Last Reality Dialogue (Forge 1.20.1) — мод для сервера и клиента

Кинематографичные диалоги для карт: камера «над плечом» у NPC, выбор ответа слева, окно диалога снизу,
встроенный редактор для творцов. Работает в мультиплеере. **Мод должен стоять и на сервере, и у игроков.**

## Сборка
GitHub -> Actions -> «Build mod» (см. .github/workflows/build.yml), jar в Artifacts. Тег `v*` создаёт релиз.

## Как это устроено (мультиплеер)
- Диалоги лежат на СЕРВЕРЕ: `<мир>/lastreality_dialogues/<имя>.json`. При первом запуске создаётся пример `jenna_intro`.
- Игрок заходит -> сервер присылает ему все диалоги. Правки -> сразу всем онлайн-игрокам.
- Сервер ведёт «сессию» каждого игрока и сам проверяет каждый выбор (клиент шлёт только номер ответа).
  Команды из диалога выполняет сервер (уровень 2), клиент их не присылает — подделать нельзя.
- Диалог сам завершается, если игрок умер / сменил измерение / ушёл дальше 48 блоков / NPC пропал.
- Редактировать могут только игроки с **OP (уровень 2+) в креативе** — проверяется на сервере при каждом сохранении/удалении/привязке.

## Запуск диалога
- Командой (работает из командных блоков и функций):
  `/dialogue start <игроки> <диалог> [<npc>]`
  например `/dialogue start @p jenna_intro @e[tag=jenna,limit=1]`. Без `<npc>` берётся ближайшая живая сущность в 8 блоках.
- ПКМ по сущности с тегом `dialogue.<имя>` (тег ставит кнопка «Привязать» в редакторе или `/tag @e[...] add dialogue.jenna_intro`).
  OP в креативе с Shift нажимает как обычно (без диалога).
- `/dialogue stop <игроки>`, `/dialogue reload` (перечитать json с диска), `/dialogue edit [диалог]` (редактор).

## Редактор: `/dialogue edit [имя]`
Смотрите на NPC и вводите команду — он станет «целью» (предпросмотр, привязка, съёмка ракурса).
Интерфейс — «док» слева, весь остальной экран остаётся свободным под живой кадр.
- **Шапка:** имя диалога (оранжевая точка = есть несохранённое), `Играть`, `Сохранить` (Ctrl+S), `×`, `‹` — свернуть панель, чтобы увидеть кадр целиком.
- **Список узлов** (слева): карточки «id + говорящий + текст», звезда = стартовый, `+` — новый узел, `×` при наведении — удалить.
- **Реплика:** id узла (Enter — переименовать), говорящий, текст с предпросмотром переноса строк, «Что дальше», команды при входе.
- **Ответы:** чипы 1…8 + `+`; текст, иконка (с миниатюрой, `›` — встроенные), «Куда ведёт», команды, удаление.
- **Камера:** «Ракурс применяется к: всему диалогу / только этому узлу»; трекпады (тяните мышью, колёсико — шаг, двойной клик — сброс):
  Дистанция, Высота, Угол, Плавность, Смещение (NPC правее в кадре), Наклон, FOV; режим «От игрока / От взгляда NPC»;
  «NPC смотрит в камеру». **Предпросмотр** — живая камера на цели + направляющие «правило третей».
  **Снять с вида** — вы летаете (креатив), нажимаете Enter (клавиша настраивается), вид превращается в ракурс. Esc — отмена.
- **Диалог:** стартовый узел, привязка к NPC (Привязать/Отвязать), сводка.
У каждого узла может быть свой ракурс — камера плавно «переезжает» при переходе.

## Команды внутри диалога
В полях «Команды» несколько команд разделяются `;;`. Подстановки: `%player%` — ник игрока, `%npc%` — UUID собеседника.
Примеры: `give %player% minecraft:apple 1 ;; scoreboard players set %player% quest 1 ;; tp %npc% 0 64 0`

## Формат json (если правите руками, потом /dialogue reload)
{ "start": "ask", "camera": { ... }, "nodes": { "ask": { "speaker": "..", "text": "..", "commands": [".."],
  "camera": { ... }, "choices": [ { "text": "..", "icon": "ns:textures/..png", "next": "id", "commands": [".."] } ], "next": "id" } } }
Узел без choices и без next — конец диалога. Имя диалога: a-z, 0-9, _ (до 40).

## Иконки и ресурсы
`assets/lastreality/textures/gui/icons/*.png` — сейчас заглушки 32x32. Свои иконки можно положить в любой ресурспак
и указать путь в поле «Иконка».

## API для аддонов
`DialogueChoiceEvent` (сервер, MinecraftForge.EVENT_BUS) — игрок выбрал ответ.
